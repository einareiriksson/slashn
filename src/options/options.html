How to type a command

In the address bar type s, a space, then:

me21n – open an app on the default system
tst me23n 4500001234 – another system, with a value
manage purchase – search titles
acd – launchpad home · ? – list systems

The toolbar icon opens the same launcher as a popup.

Systems

The SAP systems you launch into. The key is what you type after s.

Aliases

Short names and t-codes for Fiori apps. Editing a built-in row makes a personal copy; hiding one removes it from suggestions.

New alias

Typing a t-code as the alias is how you map a legacy transaction. Parameter is the URL key a trailing value is sent as.

Import or export CSV

Columns: alias, semanticObject, action, appId, tcodes, title, paramKey, editions. Lists are ;-separated.

Discovered apps

What each system actually offers your user, read from its launchpad. These rank first in suggestions.

Open tabs

Every browser tab on a registered system or a page that looks like a Fiori launchpad, across all windows. Click a row to switch to it.
